# Liberty City — фанатская заставка

Проект находится в [`gta4-cinematic/`](gta4-cinematic/README.md). В нём — 16 исходных и обработанных фотографий, монтажные слои, исходники, музыка и готовый видеорендер.

- [Посмотреть заставку](gta4-cinematic/output/gta4_liberty_city_intro.mp4) — 1920×1080, 24 кадра/с, 64 секунды.
- [Структура и повторный рендер](gta4-cinematic/README.md).
- [План сцен](gta4-cinematic/project/SHOT_LIST.md).

Музыка в текущей версии специально синтезирована для монтажа. Это **не оригинальный трек GTA IV**; если нужен конкретный трек, потребуется его файл и новая синхронизация. Видео — неофициальная фанатская работа, не связанная с Rockstar Games.
