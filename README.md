# Кинематографические фотоинтро

Две отдельные версии в стиле GTA IV используют общие городские фоны, шрифты и предоставленную музыку. Фотографии и готовые видео версий сохранены раздельно. Каждый фотоэпизод в обоих роликах использует одну движущуюся маскированную вырезку без дублирования снимка в фоне; между фотографиями — склейки без наложения.
