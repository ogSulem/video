## Approval gates

Work in sequence. All approved references remain locked and must not be modified or regenerated. The 77-second v1 edit has been rendered and technically checked; it uses still-based 2D motion and the approved backup card. Any new scene imagery, reference-image-to-video generation, official logo, or replacement footage remains a separate approval gate.

## Factual advertising safeguard

Before any public release, verify the center's existence and name, actual services and equipment, staff credentials, website/domain, and all implied outcomes. Do not present proposed capabilities as available facts.
