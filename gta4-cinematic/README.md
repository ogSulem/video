# Spartak — кинематографическое фотоинтро

## Готовый ролик

[`output/spartak_intro.mp4`](output/spartak_intro.mp4) — заставка в стиле GTA IV: 1920×1080, 24 кадра/с, длительность 1:09,250. На первом кадре видна надпись «Spartak»; она остаётся до 3,50 с. На кадре 84 происходит прямая склейка к первой фотографии под ударный акцент. Сразу после неё идут все четыре новые фотографии, затем — все прежние 16. Дополнительных титров, номеров и финальной карточки GTA IV нет.

Использован предоставленный `audio/gta 4 — main theme.m4a`. Чтобы совместить короткую заставку с первой повторяющейся ударной атакой, в ролик взят трек **начиная с 1,340 с исходного файла**: его акцент на 4,840 с звучит на 3,500 с видео. Скорость трека не менялась. Последующие склейки или центры переходов привязаны к измеренным музыкальным акцентам; один тихий акцент оценён по сетке. Последнее фото и музыка плавно затухают. Подробности измерений и ограничений — в [`project/QC_REPORT.md`](project/QC_REPORT.md), последовательность кадров — в [`project/SHOT_LIST.md`](project/SHOT_LIST.md).

## Состав проекта

```text
gta4-cinematic/
├── originals/                    # 20 оригинальных фотографий без изменения
├── processed/                    # цветокоррекция в исходном разрешении
├── assets/
│   ├── cinematic_16x9/           # индивидуальные кадрирования
│   ├── intro_masks_initial/      # сохранённые исходные маски
│   ├── intro_masks/              # итоговые маски выделения людей
│   ├── masks/                    # две ранее уточнённые исходные маски
│   ├── plates/                   # пять сгенерированных городских фонов
│   └── fonts/                    # шрифты с лицензиями OFL
├── audio/
│   ├── gta 4 — main theme.m4a    # предоставленный аудиофайл
│   └── original_score_90bpm.m4a # прежняя подложка, здесь не используется
├── output/spartak_intro.mp4
└── project/                      # исходники, сетка монтажа и проверка
```

В 15 сценах люди выделены из фотографий; в пяти сценах со сложными позами или предметами сохранены фотопанели, чтобы не отрезать людей и детали. Для новых портретов дополнительно очищены контуры и восстановлены видимые пряди волос и край банки; в нескольких прежних масках убраны оставшиеся детали фона. Лица не генерировались и не заменялись. Контуры остаются графической стилизацией, не профессиональной ротоскопией; городские фоны созданы отдельно и не изображают реальные места съёмки.

Файлы `processed/` имеют исходные размеры после EXIF-поворота и сохранены в JPEG с качеством 95: это повторное сжатие **с потерями**. Оригиналы не изменены. Дополнительные PNG без нового JPEG-сжатия создаёт `process_photos.py --lossless`; эта команда не восстанавливает качество исходных JPEG.

## Как пересобрать

Нужны Python 3.11+ и FFmpeg с `libx264`; если системного FFmpeg нет, используется бинарник `imageio-ffmpeg`. Из корня репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r gta4-cinematic/project/requirements.txt

# Необязательно: восстановить итоговые маски из сохранённых исходных.
python gta4-cinematic/project/refine_people_masks.py

# Перепроверить музыкальные акценты, собрать видео и выполнить контроль.
python gta4-cinematic/project/analyze_music.py
python gta4-cinematic/project/render_intro.py
python gta4-cinematic/project/validate_intro.py
```

Проверка сохраняет контактные листы сцен и переходов в `.qc/`. Быстрый тест первых шести сцен: `render_intro.py --test-scenes 6`; результат будет в `.qc/intro_test.mp4`. Необязательная повторная цветокоррекция всех снимков: `python gta4-cinematic/project/process_photos.py`; флаг `--only-new` обрабатывает только четыре новые фотографии. Маски уже сохранены, поэтому MediaPipe для рендера не нужен.

Для пересоздания исходных масок дополнительно нужен `mediapipe==0.10.21`. На Linux без графической библиотеки `libGL` после установки MediaPipe может потребоваться восстановить headless-версию OpenCV, поскольку MediaPipe также устанавливает обычный OpenCV:

```bash
python -m pip install mediapipe==0.10.21
python -m pip install --force-reinstall --no-deps 'opencv-python-headless>=4.10,<4.11'
python gta4-cinematic/project/prepare_intro_masks.py  # --only-new: только четыре новые
python gta4-cinematic/project/refine_people_masks.py
```

После пересоздания масок проверьте результат вручную.

Ритмическая сетка и проверка SHA-256 относятся к **конкретному предоставленному файлу**. Подмена музыки или изменение её точки входа потребует повторного измерения `MUSIC_ACCENTS` и `MUSIC_START` в `intro_design.py`. Рендерер намеренно отклоняет изменённый аудиофайл. `compose_score.py` относится к прежней версии и в этой сборке не используется.

## Права

Это неофициальная фанатская работа, не созданная и не одобренная Rockstar Games. Ролик включает предоставленный аудиотрек; перед публичной публикацией необходимо проверить права на музыку и получить согласие людей на фотографиях.
