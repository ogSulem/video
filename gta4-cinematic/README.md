# Spartak — кинематографическое фотоинтро

## Готовый ролик

[`output/spartak_intro.mp4`](output/spartak_intro.mp4) — заставка 1920×1080, 24 кадра/с, длительностью 1:03,292. В ней использованы все 16 фотографий и добавленный вами аудиофайл `audio/gta 4 — main theme.m4a`. В метаданных исходного файла указано, что это версия **slowed**. Надпись «Spartak» видна с самого первого кадра; титры, номера и названия сцен поверх фотографий, а также прежняя финальная карточка GTA IV убраны.

Монтаж привязан к музыкальным акцентам именно этой версии трека: на кадр округлены центры растворений и сдвигов или точки прямых склеек. Отклонение от измеренных акцентов — не более 20,3 мс, то есть менее половины кадра при 24 fps. Один тихий акцент взят по ритмической сетке соседних ударов. Последнее фото и музыка плавно затухают; видео не содержит отдельного финального титра. Подробности и ограничения измерения — в [`project/QC_REPORT.md`](project/QC_REPORT.md).

## Состав проекта

```text
gta4-cinematic/
├── originals/                    # 16 оригинальных фотографий без изменения
├── processed/                    # цветокоррекция в исходном разрешении
├── assets/
│   ├── cinematic_16x9/           # индивидуальные кадрирования для видео
│   ├── intro_masks_initial/      # сохранённые маски до последнего уточнения
│   ├── intro_masks/              # итоговые маски выделения людей
│   ├── masks/                    # две ранее уточнённые исходные маски
│   ├── plates/                   # пять сгенерированных городских фонов
│   └── fonts/                    # шрифты с лицензиями OFL
├── audio/
│   ├── gta 4 — main theme.m4a    # предоставленный аудиофайл
│   └── original_score_90bpm.m4a # прежняя подложка, в новом ролике не используется
├── output/spartak_intro.mp4
└── project/                      # исходники, сетка монтажа и проверка
```

В 12 сценах люди выделены из настоящих фотографий; в четырёх кадрах со сложными позами сохранены цельные фотопанели, чтобы не отрезать руки и предметы. Восемь проблемных масок дополнительно уточнены: убраны отдельные фрагменты фона, восстановлены реальные детали одежды и волос. Лица не генерировались и не заменялись. Контуры остаются графической стилизацией, а не профессиональной ротоскопией; городские фоны созданы отдельно и не изображают реальные места съёмки.

Файлы `processed/` имеют исходные размеры после EXIF-поворота и сохранены в JPEG с качеством 95: это повторное сжатие **с потерями**. Оригиналы не изменены. Дополнительные PNG без нового JPEG-сжатия создаёт `process_photos.py --lossless`; эта команда не восстанавливает качество исходных JPEG.

## Как пересобрать

Нужны Python 3.11+ и FFmpeg с `libx264`; если системного FFmpeg нет, используется бинарник `imageio-ffmpeg`. Из корня репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r gta4-cinematic/project/requirements.txt

# Необязательно: восстановить итоговые маски из сохранённых исходных.
python gta4-cinematic/project/refine_people_masks.py

# Перепроверить музыкальные акценты, собрать видео и выполнить контроль.
python gta4-cinematic/project/analyze_music.py
python gta4-cinematic/project/render_intro.py
python gta4-cinematic/project/validate_intro.py
```

Проверка сохраняет контактные листы сцен и переходов в `.qc/`. Для быстрого теста первых трёх сцен доступен `render_intro.py --test-scenes 3`; результат будет в `.qc/intro_test.mp4`. Необязательная повторная цветокоррекция: `python gta4-cinematic/project/process_photos.py`. Маски уже сохранены, поэтому MediaPipe для рендера не нужен. Если нужны новые исходные маски, `prepare_intro_masks.py` требует дополнительно `mediapipe==0.10.21`; затем запустите `refine_people_masks.py` и вручную проверьте результат.

Ритмическая сетка и проверка SHA-256 рассчитаны на **конкретный предоставленный файл**. Подмена музыки или смещение её начала без повторного измерения `MUSIC_ACCENTS` в `intro_design.py` нарушит синхронизацию; рендерер намеренно отклоняет изменённый аудиофайл. Доступный в проекте `compose_score.py` относится к прежней версии и в этой сборке не используется.

## Права

Это неофициальная фанатская работа, не созданная и не одобренная Rockstar Games. Ролик включает предоставленный аудиотрек; перед публичной публикацией необходимо проверить права на музыку и получить согласие людей на фотографиях.
