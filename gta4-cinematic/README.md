# Liberty City — фанатская заставка из фотографий

## Что готово

[`output/gta4_liberty_city_intro.mp4`](output/gta4_liberty_city_intro.mp4) — 64-секундная заставка 1920×1080, 24 кадра/с: 16 ваших фото, 19 сцен, городские планы, графические панели, выделенные люди, движение слоёв и монтажные переходы. В 12 сценах персонажи вырезаны из настоящих фотографий; в четырёх сложных групповых/сидячих кадрах сохранены целые фотографии в графических панелях, чтобы не отрезать руки и не портить позы. Это анимация неподвижных фотографий, а не съёмка или генерация движущихся людей.

**Звук:** для ролика написан и синтезирован отдельный инструментальный саундтрек `audio/original_score_90bpm.m4a`. Точки смены сцен выставлены на сетку 90 BPM; музыка не является оригинальным треком GTA IV и не содержит семплов из игры. Если нужен конкретный оригинальный трек, пришлите аудиофайл: потребуется подогнать монтаж под него. Автоматическая подмена и синхронизация не выполняются.

## Структура

```text
gta4-cinematic/
├── originals/                   # все 16 оригиналов без изменения
├── processed/                   # цветокоррекция в исходном разрешении
├── assets/
│   ├── cinematic_16x9/          # индивидуально кадрированные фото для видео
│   ├── intro_masks/             # маски выделения, используемые монтажом
│   ├── masks/                   # две исходные уточнённые маски
│   ├── plates/                  # 5 созданных городских фонов без людей
│   ├── fonts/                   # шрифты Anton и IBM Plex Mono, с лицензиями OFL
│   └── contact_sheet.jpg        # обзор оригиналов
├── audio/original_score_90bpm.m4a
├── output/gta4_liberty_city_intro.mp4
└── project/                     # исходники и документация
```

Лица и фигуры взяты из предоставленных фотографий; лица не генерировались и не заменялись. Контуры созданы сегментацией и обводкой, некоторые края могут быть неидеальны. Городские фоны сгенерированы отдельно, без людей. Вырезанные фигуры намеренно оформлены графически, а не как фотореалистичная подстановка в новое место.

Файлы `processed/` имеют исходные размеры после EXIF-поворота и сохранены в JPEG с качеством 95: это высококачественное, но **не без потерь** повторное сжатие. Оригиналы не изменены. Для дополнительных PNG без последующего JPEG-сжатия есть команда `process_photos.py --lossless` (потребуется значительно больше места); качество уже сжатого оригинала она не восстанавливает.

## Как пересобрать

Нужны Python 3.11+ и FFmpeg с `libx264`; если системного FFmpeg нет, используется бинарник `imageio-ffmpeg`. Из корня репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r gta4-cinematic/project/requirements.txt

# Необязательно: пересоздать цветокоррекцию из оригиналов.
python gta4-cinematic/project/process_photos.py

# Пересоздать собственную музыку и экспортировать видео.
python gta4-cinematic/project/compose_score.py
python gta4-cinematic/project/render_intro.py

# Проверить итог и собрать обзор кадров в .qc/.
python gta4-cinematic/project/validate_intro.py
```

Для дополнительных полноразмерных PNG:

```bash
python gta4-cinematic/project/process_photos.py --lossless
```

Маски уже сохранены, поэтому MediaPipe для рендера не нужен. Их необязательное пересоздание через `prepare_intro_masks.py` требует дополнительно `mediapipe==0.10.21` и установки совместимого OpenCV; после пересоздания нужно вручную проверить края.

## Если вы предоставите музыкальный файл

```bash
python gta4-cinematic/project/render_intro.py \
  --music gta4-cinematic/audio/ВАШ_ТРЕК.mp3 --music-offset 0
```

Будет создан отдельный файл `output/gta4_liberty_city_with_user_music.mp4`. Команда только заменяет звук; **автоматического определения ритма нет**. Если трек короче ролика, остаток дополняется тишиной. Чтобы синхронизировать монтаж с новой композицией, после прослушивания измените длительности `frames` в списке `SCENES` файла `project/intro_design.py` и повторно выполните рендер с `--music`. Единица тайминга — кадр при 24 fps; план кадров — в `project/SHOT_LIST.md`.
