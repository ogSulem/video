# Dubravnaya — отдельная версия фотоинтро

## Готовое видео

[`output/dubravnaya_intro.mp4`](output/dubravnaya_intro.mp4) — новая версия в стиле предыдущей заставки: **1920×1080, 24 кадра/с, 58,292 с**. На первом кадре видна надпись **Dubravnaya**. В 3,500 с заставка напрямую сменяется первой фотографией, затем использованы все 17 новых фотографий по одному разу, в порядке вложений. Дополнительных титров и финальной карточки нет.

Музыка — тот же предоставленный [`gta 4 — main theme.m4a`](../audio/gta%204%20%E2%80%94%20main%20theme.m4a), начиная с 1,340 с исходника. Его удар на 4,840 с приходится на первую склейку в 3,500 с видео. Последующие склейки и середины переходов следуют той же музыкальной сетке; одна тихая отметка оценена по сетке. Последняя фотография и музыка плавно затухают. Список кадров — в [`project/SHOT_LIST.md`](project/SHOT_LIST.md), результаты проверки — в [`project/QC_REPORT.md`](project/QC_REPORT.md).

## Где фотографии

```text
dubravnaya/
├── originals/                 # ровно 17 новых JPEG без изменений
├── processed/                 # отдельные обработанные копии для рендера
├── assets/intro_masks/        # маски семи фотографических вырезок
├── project/                   # сценарий, рендер, проверки и SHA-256 оригиналов
└── output/dubravnaya_intro.mp4
```

Все оригиналы сохранены под исходными именами; их контрольные суммы — в [`project/ORIGINALS.sha256`](project/ORIGINALS.sha256). Фотографии из предыдущей версии в этот монтаж **не включены**. Семь сцен используют выделенные фигуры, десять — фотопанели: для сложных поз и предметов это позволяет избежать повреждённых вырезок. Лица не генерировались и не заменялись. В обработанных копиях выполнены цветокоррекция и повторное JPEG-сжатие с потерями; большая сторона ограничена 2560 пикселями. Неизменённые оригиналы хранятся в полном исходном разрешении.

Чтобы не дублировать общие материалы, версия использует городские фоны и шрифт из [`../assets/`](../assets/) и тот же трек из [`../audio/`](../audio/). Это отдельно созданные городские изображения, а не фотографии из предыдущего ролика. Прошлый [`output/spartak_intro.mp4`](../output/spartak_intro.mp4), его фотографии и монтажные файлы не заменены.

## Повторная сборка

Нужны Python 3.11+ и FFmpeg с `libx264`; если системного FFmpeg нет, используется бинарник `imageio-ffmpeg`. Из корня репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r gta4-cinematic/project/requirements.txt

# Если нужно, пересоздать обработанные копии из новых оригиналов.
python gta4-cinematic/dubravnaya/project/prepare_images.py

# Собрать отдельный MP4 и выполнить техническую проверку.
python gta4-cinematic/dubravnaya/project/analyze_music.py
python gta4-cinematic/dubravnaya/project/render_intro.py
python gta4-cinematic/dubravnaya/project/validate_intro.py
```

Для рендера MediaPipe не нужен: маски уже сохранены. Для их необязательного пересоздания установите `mediapipe==0.10.21`; на Linux без `libGL` после этого может понадобиться снова установить headless OpenCV:

```bash
python -m pip install mediapipe==0.10.21
python -m pip install --force-reinstall --no-deps 'opencv-python-headless>=4.10,<4.11'
python gta4-cinematic/dubravnaya/project/prepare_masks.py
```

Проверяйте пересозданные маски визуально. Тест первых шести сцен: `python gta4-cinematic/dubravnaya/project/render_intro.py --test-scenes 6`; он записывается в `.qc/dubravnaya/`, не заменяя финальный файл. Временные файлы рендера находятся в `.cache/`. Рендерер использует и проверяет конкретный аудиофайл и контрольные суммы новых оригиналов; при замене музыки ритмическую сетку необходимо измерить заново.

Видео неофициальное и не связано с Rockstar Games. Права на музыку и согласие изображённых людей следует проверить до публичной публикации.
