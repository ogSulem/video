# Dubravnaya — отдельная версия фотоинтро

## Готовое видео

[`output/dubravnaya_intro.mp4`](output/dubravnaya_intro.mp4) — новая версия в стиле предыдущей заставки: **1920×1080, 24 кадра/с, 58,292 с**. На первом кадре видна надпись **Dubravnaya**. В 3,500 с заставка напрямую сменяется первой фотографией, затем использованы все 17 новых фотографий по одному разу, в порядке вложений. Дополнительных титров и финальной карточки нет.

Музыка — тот же предоставленный [`gta 4 — main theme.m4a`](../audio/gta%204%20%E2%80%94%20main%20theme.m4a), начиная с 1,340 с исходника. Его удар на 4,840 с приходится на первую склейку в 3,500 с видео. Все последующие склейки следуют той же музыкальной сетке; одна тихая отметка оценена по сетке. Последняя фотография и музыка плавно затухают. Список кадров — в [`project/SHOT_LIST.md`](project/SHOT_LIST.md), результаты проверки — в [`project/QC_REPORT.md`](project/QC_REPORT.md).

## Где фотографии

```text
dubravnaya/
├── originals/                 # ровно 17 новых JPEG без изменений
├── processed/                 # отдельные обработанные копии для рендера
├── assets/intro_masks/        # семь масок предыдущей версии
├── assets/motion_masks_source/ # исходные маски остальных десяти снимков
├── assets/motion_masks/       # 17 масок текущей версии
├── project/                   # сценарий, рендер, проверки и SHA-256 оригиналов
└── output/dubravnaya_intro.mp4
```

Все оригиналы сохранены под исходными именами; их контрольные суммы — в [`project/ORIGINALS.sha256`](project/ORIGINALS.sha256). Фотографии Spartak в этот монтаж **не включены**. Во **всех 17 фотоэпизодах** показана единственная маскированная вырезка; фон — отдельное городское изображение, а не вторая копия фото. Вырезка непрерывно двигается и масштабируется независимо от фона: это 2.5D-анимация фотографии, без генерации новых движений тела или мимики. Для исключения двойного появления человека между фотографиями все переходы выполнены прямыми склейками на музыкальных акцентах, без наложения кадров. Для сложных кадров вручную восстановлены детали и предметы; лица не генерировались и не заменялись. Подробности и ограничения масок — в [`../project/MASK_NOTES.md`](../project/MASK_NOTES.md). В обработанных копиях выполнены цветокоррекция и повторное JPEG-сжатие с потерями; большая сторона ограничена 2560 пикселями. Неизменённые оригиналы хранятся в полном исходном разрешении.

Для чёткости итогового 1080p-видео фоновые композиции хранятся во временных PNG без дополнительного JPEG-сжатия, а H.264 кодируется с `CRF 14, preset medium` без повторного перекодирования при сборке. Это не восстанавливает отсутствующие детали исходных снимков.

Чтобы не дублировать общие материалы, версия использует городские фоны и шрифт из [`../assets/`](../assets/) и тот же трек из [`../audio/`](../audio/). Это отдельно созданные городские изображения, а не фотографии из другого ролика. Ролик [`Spartak`](../output/spartak_intro.mp4) также обновлён; его фотографии и видео хранятся отдельно.

## Повторная сборка

Нужны Python 3.11+ и FFmpeg с `libx264`; если системного FFmpeg нет, используется бинарник `imageio-ffmpeg`. Из корня репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r gta4-cinematic/project/requirements.txt

# Если нужно, пересоздать обработанные копии из новых оригиналов.
python gta4-cinematic/dubravnaya/project/prepare_images.py

# Необязательно: восстановить сохранённые итоговые маски обоих роликов.
python gta4-cinematic/project/refine_motion_masks.py

# Собрать отдельный MP4 и выполнить техническую проверку.
python gta4-cinematic/dubravnaya/project/analyze_music.py
python gta4-cinematic/dubravnaya/project/render_intro.py
python gta4-cinematic/dubravnaya/project/validate_intro.py
```

Для рендера MediaPipe не нужен: маски уже сохранены. Для их необязательного пересоздания установите `mediapipe==0.10.21`; на Linux без `libGL` после этого может понадобиться снова установить headless OpenCV:

```bash
python -m pip install mediapipe==0.10.21
python -m pip install --force-reinstall --no-deps 'opencv-python-headless>=4.10,<4.11'
python gta4-cinematic/dubravnaya/project/prepare_masks.py
python gta4-cinematic/project/refine_motion_masks.py
```

Эти команды восстанавливают прежние семь масок и применяют сохранённые выбранные исходные маски остальных десяти кадров. Проверяйте пересозданные маски визуально. Контроль также отслеживает движение внутри маски в готовом видео и сохраняет выборки кадров. Тест первых шести сцен: `python gta4-cinematic/dubravnaya/project/render_intro.py --test-scenes 6`; он записывается в `.qc/dubravnaya/`, не заменяя финальный файл. Временные файлы рендера находятся в `.cache/`. Рендерер использует и проверяет конкретный аудиофайл и контрольные суммы новых оригиналов; при замене музыки ритмическую сетку необходимо измерить заново.

Видео неофициальное и не связано с Rockstar Games. Права на музыку и согласие изображённых людей следует проверить до публичной публикации.
