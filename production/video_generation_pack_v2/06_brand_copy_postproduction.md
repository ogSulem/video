# Brand copy and post-production rules

The three lines below are **owner-approved** and must reach the screen exactly as
written, typeset afterwards. They are never generated by a video model and never
appear inside any clip.

```
РЕАБИЛИТАЦИОННЫЙ ЦЕНТР АЛТАЙ
Твой сезон продолжается.
altaysportreab.ru
```

## Rules

- **Sequential reveal**, in this order, over the end of Clip D and the reserved
  background `references/scenes/REF-SCENE-10-final-brand-card.png`:
  name → tagline → URL. Each line holds long enough to be read once; the URL holds
  to the last frame.
- **Never generated.** No prompt in this package asks for text. If a generated clip
  comes back with any lettering, signage, watermark or UI, the clip is rejected — not
  cropped, not painted over.
- **No logo.** No official logo file exists. The decorative mountain/trail motif in
  `REF-SCENE-10` is decorative only; do not describe it as a logo, do not recreate it
  in a model, do not extend it.
- **No invented copy.** No extra lines, no claims, no phone numbers, no social handles,
  no "since 20xx", no awards, no certification badges.
- **Spelling check** before mastering: `altaysportreab.ru` (no caps, no www), and the
  name all-caps in Cyrillic as above. Tagline ends with a full stop.
- **Fonts**: a Cyrillic-capable family is already required by the existing renderer
  (`video/render_altai_commercial.py`); reuse it so V2 and the hero cut match.
- **Safe area**: keep the three lines inside the same centred bands used in v2, and keep
  them clear of the frame edges for a future 9:16 recompose.

## Compliance reminder

Before public release, verify the center's real name, services, staff credentials,
domain rights, and that no implied outcome is present. The clips deliberately contain
no diagnosis, procedure or outcome claim; keep it that way in titles and captions too.
