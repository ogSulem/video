## Почему документация не спасает

`docs.nvidia.com/nim/visual-genai/...` описывает **self-hosted NIM-контейнер**
`nvcr.io/nim/wan-ai/wan2.2:1.0.0`, а не hosted API. Доказательства из самих доков:

- «start the server with `NIM_MODEL_VARIANT=t2v` / `=i2v`» — вариант задаётся
  **переменной окружения контейнера**, у hosted-эндпоинта такой переменной нет;
- поддержка указана как «4 x 80GB GPU рекомендовано, 80GB минимум» (support matrix) —
  это требование к своему железу;
- в getting-started `invoke_url` = `http://localhost:8000/v1/videos/generations`;
- контейнер на NGC помечен «Subscription required to access this content».

То есть маршрут `/v1/videos/generations` с `wan-ai/wan2.2` существует только у
контейнера, который вы запускаете сами. На `integrate.api.nvidia.com` его нет.

## Что это значит для проекта

- Тестовый клип через NVIDIA **невозможен**. Workflow
  `.github/workflows/nvidia-video-test-clip.yml` оставлен в репозитории, но
  заблокирован и не должен запускаться.
- Ограничения hosted-видео (длительность, разрешение, цена, квота) **устанавливать
  не нужно** — hosted-видео не существует, вопрос снят.
- Документированные пределы самого Wan2.2 (если считать по self-hosted):
  832×480, `seconds` с примером 4 — но это не наш случай.
- Планирование монтажа под 4 секунды **не требуется** по этой причине.

## Что НЕ проверено (и почему)

- Цена, квота, entitlements — `/v1/models` их не отдаёт, а моделей для видео нет,
  так что проверять нечего.
- Другие возможные видео-модели по именам (`google/diffusiongemma-26b-a4b-it`,
  `stepfun-ai/step-5-preview`, `minimaxai/minimax-m3.1-flash`) — имя не является
  доказательством возможности, а гадать по имени и бить в неподтверждённые
  эндпоинты запрещено правилами проекта.

## Возможные дальнейшие пути (нужно решение владельца)

1. **Battle mode** — другой провайдер с реальным hosted i2v (Wan 2.2/2.5, Kling,
   Runway, Luma, fal.ai, Replicate, Together и т.п.), вызовы через GitHub Actions,
   ключ — в секрете репозитория. Каждый провайдер требует своей регистрации.
2. **Self-hosted Wan2.2** — формально возможно, но нужен GPU 80GB и Docker,
   то есть терминал и аренда железа. Против правила «без терминала» и дорого.
3. **Отказ от AI-видео** — тогда меняется весь замысел (запрещено: слайдшоу,
   Ken Burns, интерполяция), поэтому этот путь не рекомендуется.
