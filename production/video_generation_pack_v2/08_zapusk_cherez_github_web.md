# Запуск через веб-интерфейс GitHub — без терминала

Два workflow. Первый — бесплатная проверка доступа. Второй — **один** тестовый клип.
Второй без вашего подтверждения денег не тратит.

Репозиторий: **github.com/ogSulem/video**
Ветка: **arena/f2f34461-video**

---

## Шаг 1. Проверка доступа (бесплатно)

1. Откройте <https://github.com/ogSulem/video>
2. Вверху выберите вкладку **Actions**.
3. В левом списке нажмите **NVIDIA video capability discovery**.
4. Справа нажмите кнопку **Run workflow** (серая кнопка с выпадающим списком).
5. В поле **Use workflow from** выберите **arena/f2f34461-video**.
6. Поле `probe_model_id` оставьте как есть (`wan-ai/wan2.2`), `fetch_docs` — включено.
7. Нажмите зелёную **Run workflow**.
8. Обновите страницу, откройте появившийся запуск (жёлтый кружок → зелёная галочка или
   красный крест), дождитесь окончания. Обычно 1–2 минуты.
9. Нажмите на запуск → внизу страницы блок **Summary**. Там будет:
   - сколько моделей видит ваш ключ;
   - есть ли в списке видеомодели (`wan`, `video`, `i2v`, `t2v`, `cosmos`, `animate`);
   - запись модели `wan-ai/wan2.2`, если она доступна;
   - цитаты из официальной документации NVIDIA.
10. Внизу того же запуска — блок **Artifacts** → `nvidia-discovery-report` (скачивается zip).

**Что делать с результатом:** пришлите мне текст из блока Summary (не скриншот,
а текст — его можно выделить и скопировать). Я по нему скажу точный id модели и
правильные параметры.

### Если запуск красный

- **«NVIDIA_API_KEY is not configured»** — секрет не добавлен или добавлен не в тот
  репозиторий. Settings → Secrets and variables → Actions → New repository secret,
  имя ровно `NVIDIA_API_KEY`.
- **HTTP 401 / 403 в Summary** — ключ недействителен или отозван. Создайте новый на
  build.nvidia.com и обновите секрет (Settings → Secrets → NVIDIA_API_KEY → Update).
- **HTTP 404 на `/v1/models`** — редко, но значит, что базовый адрес для вашего
  аккаунта другой; пришлите Summary, поправлю.

## Шаг 2. Один тестовый клип

**Сначала дождитесь, что Шаг 1 прошёл и в списке есть видеомодель.** Если её нет —
не запускайте Шаг 2, а пришлите Summary: значит, у ключа нет доступа к генерации
видео, и мы идём через battle mode.

1. **Actions** → в левом списке **NVIDIA video - single test clip (image-to-video)**.
2. **Run workflow** → ветка **arena/f2f34461-video**.
3. Заполните поля:

| Поле | Что вписать |
|---|---|
| `confirm` | `NO` — **первый раз обязательно NO** |
| `model` | id из Шага 1 (по умолчанию `wan-ai/wan2.2`) |
| `size` | `832x480` (пока не узнаем другие варианты) |
| `seconds` | `4` |
| `image_field` | `image` |
| `reference` | `references/scenes/REF-SCENE-01-ski-descent.png` |
| `prompt_file` | оставить по умолчанию |

4. **Run workflow** → дождитесь окончания.

При `confirm = NO` **ничего не генерируется**: workflow проверяет секрет, проверяет,
что модель есть в каталоге, собирает запрос и показывает его в Summary. Это
бесплатно. Так мы убеждаемся, что маршрут и параметры верные.

5. Если dry-run зелёный и Summary выглядит правильно — **Run workflow ещё раз**,
   те же поля, но `confirm` = `GENERATE`. Это будет **один** платный запрос. Повторов
   не будет: при ошибке workflow остановится и покажет ответ сервера.
6. Результат: внизу запуска **Artifacts** → `nvidia-test-clip` (zip). Внутри
   `clip_test.mp4` и `report.json` (длительность, разрешение, fps, кадры, sha256),
   плюс `payload.preview.json` и `resp_slim.json`.

**Пришлите мне:** скачанный `clip_test.mp4` (можно перетащить в чат) или ссылку на
артефакт. Я посмотрю клип по семи критериям из `prompts/test_carve_i2v.md` и скажу,
годится ли модель для остальных четырёх клипов.

### Если тест красный

Workflow **не повторяет** запрос автоматически — так задумано, чтобы не тратить
деньги. В Summary будет ответ сервера с текстом ошибки. Пришлите его: чаще всего
нужно поменять одно поле (`image_field` на `input_reference` или `image_url`) или
уменьшить `size`.

## Чего эти workflow не делают

- не выводят ключ в логи, отчёты и артефакты (он маскируется, ответы проходят через
  редактор, self-test редактора обязателен);
- не коммитят ни видео, ни секреты (права только на чтение, есть проверка чистоты
  репозитория в конце);
- не перезаписывают V1/V2 и утверждённые изображения;
- не запускают остальные клипы — для них будет отдельный workflow после вашего
  одобрения теста.
