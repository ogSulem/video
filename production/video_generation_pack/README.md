# Пакет для генерации движения — «RETURN TO THE SLOPE»

Всё, что нужно, чтобы заменить в готовом 77-секундном фильме четыре окна настоящим
ИИ-видео. Пять файлов, по порядку чтения:

| Файл | Зачем |
|---|---|
| [`01_plan_i_tayming.md`](01_plan_i_tayming.md) | что генерим, куда это встаёт по озвучке, что нельзя нарушать |
| [`02_promty_dlya_battle_mode.md`](02_promty_dlya_battle_mode.md) | 4 готовых промпта (EN) + negative prompt |
| [`03_instruktsiya_nvidia_build.md`](03_instruktsiya_nvidia_build.md) | запуск на NVIDIA со своим ключом, одной командой |
| [`04_kak_peredat_v_battle_mode.md`](04_kak_peredat_v_battle_mode.md) | что загрузить и что вставить в battle mode |
| [`prompts_export.json`](prompts_export.json) | те же промпты машинночитаемо — их берёт скрипт |
| [`references/`](references/) | 8 одобренных кадров, переименованных под клипы |

Сборка после генерации:

```bash
.venv/bin/python video/tools/assemble_hero_clips.py --force
```

## Честно о текущем фильме

- `video/final/altai_rehabilitation_commercial_v2.mp4` — 77 с, собран из одобренных
  **фотокадров** с плавными цифровыми наездами. Это не видео, тела в нём не двигаются.
- `video/shots/altai_carve_fall_v1/final/altai_carve_fall_v1_5s.mp4` — 5-секундный
  непрерывный кадр «карвинг → падение», собранный процедурно из сгенерированных
  ключевых кадров (оптический поток + симуляция затвора). Это честное движение
  внутри кадра, но не генеративное фотореалистичное видео.
- Полноценное фотореалистичное видео требует внешнего генератора. Эта песочница до
  них не достаёт (интернет ограничен GitHub/PyPI), поэтому в пакете — всё для
  запуска у вас.

## Что уже проверено

Скрипт сборки протестирован на четырёх тестовых клипах 1280×720 / 30 fps:
кадры приводятся к 1920×1080 обрезкой без растяжения, окна укорачиваются под
фактическую длину клипа, на границах — наплыв 0,4 с, на выходе ровно 77,00 с,
1920×1080, 24 fps, звук — исходный одобренный, без перекодирования.
