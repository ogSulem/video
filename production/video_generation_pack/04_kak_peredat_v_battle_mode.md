# Как передать проект в battle mode (4 генерации)

Battle mode не умеет брать файлы из GitHub — ему нужны **файлы, загруженные вручную**,
и **текст промпта**. Всё готово, остаётся 4 раза повторить одну процедуру.

---

## Что загружать

Папка `production/video_generation_pack/references/`. Для каждого клипа — свой
референс (DEF), при желании альтернатива (ALT):

| Клип | Основной файл | Альтернатива |
|---|---|---|
| A — карвинг и падение | `CLIP-A_def_P87-ski-descent.png` | `CLIP-A_alt_carve-close.png` |
| A — финал, если нужен второй кадр | `CLIP-A_end_aftermath.png` | — |
| B — приезд | `CLIP-B_def_exterior.png` | `CLIP-B_alt_reception.png` |
| C — восстановление | `CLIP-C_def_exercise.png` | `CLIP-C_alt_physio.png` |
| D — возвращение | `CLIP-D_def_return.png` | — |

Это уже одобренные и заблокированные кадры проекта (`REF-SCENE-01`, `02 v2`, `03`,
`04`, `06`, `07`, `09`) — переименованы, чтобы в чате было понятно, к какому клипу
какой файл.

Если сервис просит отдельно «первый кадр» и «последний кадр»:

- клип A: первый — `CLIP-A_def_P87-ski-descent.png`, последний — `CLIP-A_end_aftermath.png`
  (это даст управляемый переход «карвинг → сидит в снегу»);
- клип D: первый — `CLIP-D_def_return.png`, последнего кадра нет, пусть уезжает в небо;
- клипы B и C: только первый кадр.

## Что писать в поле промпта

Открыть `02_promty_dlya_battle_mode.md`, взять блок нужного клипа целиком:
строку `**Prompt (EN, с референсом):**` (текст в кавычках) и строку
`**Negative prompt:**`. Скопировать как есть — они уже составлены под ограничения
проекта (без текста, без логотипов, без графичной травмы, тот же герой и та же ось
движения).

## Что указать в настройках

```
aspect ratio:  16:9
duration:      8–10 секунд (если дают выбрать)
resolution:    1920×1080 или максимум доступного (сборщик всё равно приведёт)
motion:        умеренное — не «maximum», иначе поедут лица и лыжи
seed:          зафиксировать, если есть; при перегенерации менять только seed
```

## Порядок действий

1. Клип A → сгенерировать → посмотреть → **скачать** в
   `video/shots/ai_hero_clips/clipA.mp4`.
2. Клип B → … → `clipB.mp4`.
3. Клип C → … → `clipC.mp4`.
4. Клип D → … → `clipD.mp4`.
5. Собрать:

```bash
.venv/bin/python video/tools/assemble_hero_clips.py --force
```

Если какой-то клип не удался — **не тратьте на него все попытки**. Сборщик работает
и с тремя, и с двумя, и с одним клипом: окна без клипа остаются на одобренных
фотокадрах. Пустой вызов сборщика просто скажет, что подменять нечего.

## Что проверить у каждого клипа перед сборкой

- [ ] то же лицо и та же одежда (тёмно-синяя куртка, оранжевые акценты, графитовые штаны);
- [ ] шлем и очки на месте, без «второй головы» и лишних рук;
- [ ] лыжи прямые, палки не гнутся, ботинки в креплениях;
- [ ] нет текста, вывесок, логотипов в кадре;
- [ ] падение (клип A) неграфичное: без крови, без крупных планов травмы;
- [ ] направление движения одно и то же — сверху-справа вниз-влево;
- [ ] камера не пересекает ось действия (мы всё время со стороны подножия).

## Что присылать мне

Достаточно одного из двух:

- ссылку/файлы клипов в репозитории (`video/shots/ai_hero_clips/`) — тогда я сам
  соберу, проверю тайминги, подгоню окна и отдам финальный файл;
- либо в чат: какая модель/сервис, что вернул сервер на ошибку (если была), и какие
  клипы получились — дальше я поправлю вызов или тайминг.

Ключи API в чат присылать не нужно.
